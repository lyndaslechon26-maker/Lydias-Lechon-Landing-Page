## ⚡ The Fastest Path

```powershell
# 1. Install
npm install

# 2. While that's running, create new Supabase project at:
# https://supabase.com

# 3. Copy .env.example to .env.local
copy .env.example .env.local

# 4. Edit .env.local with your Supabase credentials

# 5. Run migrations in Supabase SQL Editor:
#    - Copy contents of: supabase/migrations/01_landing_page_complete_schema.sql
#    - Paste and run in SQL Editor

# 6. Create manager account:
#    - Go to Supabase Dashboard > Authentication > Users
#    - Add user with your email/password
#    - Copy user ID
#    - Edit and run: supabase/migrations/02_create_first_manager.sql

# 7. Start dev server
npm run dev

# 8. Visit http://localhost:3000
# 9. Login at http://localhost:3000/manager
```
